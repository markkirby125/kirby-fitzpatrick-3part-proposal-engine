## Core Patterns

- **3Part Proposal Engine**: 3-Part Proposal Framework: Common Ground (Status Quo) -> Destabilizing Problem (Cost of Inaction) -> Technical Solution (Resolution).
- **Practical Application**: High-impact RFCs, major dependency upgrade proposals, and tech-debt pitches.
- **Verification Gate**: Enforces clean syntax, zero filler, and deterministic causality.
